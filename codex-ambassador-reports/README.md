# Codex Ambassador reports — Auralis

Статус: подготовка. Участие в программе не подтверждено. Сбор материалов начинается только после принятия владельца проекта в программу и его разрешения.

## Правило для будущих сессий ChatGPT
Отчётность ведётся отдельно от списка задач разработки. Не изменять код игры, существующий backlog или настройки публикации. Когда владелец присылает результаты тестирования, скриншоты, ошибки Codex и исправления, сохранять согласованные материалы в этой ветке и папке. Не выдумывать результаты. Для каждого случая фиксировать дату, исходную задачу или ссылку на PR/commit, ожидаемый и фактический результат, условия воспроизведения, исправление и результат повторного теста (или статус «не проверено»).

## Структура будущих материалов
- `screenshots/` — согласованные скриншоты до/после.
- `bugs/` — воспроизводимые ошибки.
- `fixes/` — исправления и ссылки на коммиты.
- `testing/` — результаты проверок, включая Android.
- `achievements/` — подтверждённые достижения.
- `reports/` — ежемесячные черновики на русском и английском.

Подпапки создаются по мере появления материалов. Отчёты готовит ChatGPT на основе фактических данных; владелец проверяет и утверждает их перед отправкой или публикацией.

## Конфиденциальность
Репозиторий публичный, включая отдельные ветки. Не загружать персональные данные, секреты, токены, частные скриншоты или непубличные материалы. Для конфиденциальной отчётности использовать отдельный приватный репозиторий после согласования с владельцем. Не публиковать материалы и не отправлять их OpenAI без отдельного разрешения. Условия программы и её требования проверять после принятия.
