## Автоматические проверки

`npm test`:89 тестов,89 успешно. Начальный запуск воспроизводил38 успешных и4 падающих. Исправлена настоящая ошибка `-0` в неподвижной анимации. `npm run check`: синтаксическая проверка всех исходных модулей, сценариев и тестов, а не только прежних9 файлов.

`npm run test:browser`: Playwright + Chromium, мобильный viewport и CDP touch. Сам поднимает HTTP-сервер, закрывает его и браузер после завершения. Проверяет реальные UI-действия; состояния повышенного уровня, отдельные боевые ситуации и предметы подготавливает программно для воспроизводимости. Это не полный ручной забег с нового персонажа до42уровня.

## Браузерный сценарий

- Создание персонажа, вход в мир, загрузка без JS-ошибок.
- Настоящие touchStart/touchEnd джойстика, движение и сброс.
- Принятие задания Миры; удержание обычной атаки, попадание, XP и прогресс убийства.
- Получение урона; возрождение в деревне при нулевом HP.
- Повышение уровня через общую функцию XP; распределение силы через UI.
- Изучение и назначение навыка через дерево; боевое применение, MP и перезарядка.
- Надевание подготовленного предмета через инвентарь.
- Использование зелья и уменьшение его количества.
- Автосохранение при открытой панели; перезагрузка и проверка имени, экипировки, навыков/слотов, зелий, задания, характеристик.
- Размеры844×390,640×360,740×320: без горизонтальной прокрутки, сенсорные кнопки навыков не меньше44px.
- Сдача задания, продажа материалов и покупка зелья.
- Перенос предмета в общее хранилище и обратно через UI.
- Закрытие трёх панелей кнопками, портретная подсказка, системная пауза с закрытием NPC и возобновление.

Независимая дополнительная проверка в Chromium: создание всех6 классов; все30 навыков при ранге5 расходуют MP и блокируют HUD на cooldown;6 смен слотов сохраняют три разных имени. ## Производительность

Chromium использовал программный WebGL ANGLE/Vulkan SwiftShader. До оптимизации при одновременно выполнявшихся браузерных тестах60-секундный замер дал около7,9FPS; число объектов150 не росло, JS heap28,6–41,5МБ с очисткой GC. Это короткая проверка без обнаруженного монотонного роста памяти, а не доказательство отсутствия утечек.

В отдельном сравнении одной сцены844×390 после прогрева исходная векторная земля/декорации дали11,77FPS; только кэш земли12,44FPS; кэш земли, деревьев и домов30,30FPS. Замер — число postrender-кадров за примерно7секунд. Нагрузка и программный GPU ограничивают применимость результата. **60FPS и настоящая работа на Android пока не подтверждены.**

## Ограничения и ручная проверка телефона

Список незавершённого — [ROADMAP.md](ROADMAP.md). Перезарядки/активные эффекты сбрасываются при новом сеансе. Стрельба не проверяет препятствия на пути снаряда. Новые панели переведены, часть старого UI остаётся русской. Основные художественные ассеты временные.

На Android запустите HTTP-сервер по инструкции README, откройте LAN-адрес и проверьте два пальца одновременно: удерживать атаку правым, менять направление левым; отпустить за пределами кнопки и убедиться, что атака остановилась. Затем пройдите цикл Мира→волки→награда→магазин→Борин→перезагрузка. Проверьте сворачивание браузера, поворот экрана и15–30минут боя с замерами FPS/температуры. Сравните сохранение до и после обновления, не очищая данные сайта.

## GitHub Actions: окружение браузера

Workflow закреплён на `ubuntu-24.04` и использует установленный в официальном образе GitHub runner Google Chrome. Шаг `Verify runner Chrome` проверяет исполняемый файл, печатает версию и передаёт его путь через `CHROMIUM_PATH` браузерному сценарию. Все браузерные проверки обязательны; ошибки не игнорируются.

Первоначальный CI упал до запуска браузера: `playwright install --with-deps chromium` пытался установить дополнительные шрифты через APT, но Ubuntu-зеркала не разрешались по DNS (`Temporary failure resolving`, код APT100). Использование уже установленного браузера исключает эту ненужную загрузку системных пакетов и самого Chromium. Локальная инструкция установки Playwright-браузера для компьютеров без Chrome остаётся действительной. Опубликованная тестовая версия игры этим изменением не обновляется.
