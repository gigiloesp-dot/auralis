`js/quests/journal.js` уже выбирает только active/completed (до награды), исключая claimed. Код заданий и сохранений не изменён. Существующий `browser-task5-journal.cjs` проверяет реальные NPC-кнопки: принятие, прогресс 0/5 → 1/5 → 5/5, доступную награду, сохранение до сдачи, сдачу, немедленное отсутствие в активном журнале, claimed в save и отсутствие после reload. Он выполняется для RU/EN/ES.

Новый `browser-task7-menu.cjs` проверяет 18 сочетаний RU/EN/ES × 1536×695, 640×360, 740×320, 844×390, 915×412, 1280×720: полноэкранный фон, ровно пять отдельных кнопок, сенсорные области, отсутствие переполнения, неизменность storage, отсутствие JS errors. Дополнительно сравниваются средние RGB-пиксели 5×5 областей по обоим краям с исходным изображением, пропорционально отрисованным как cover. Усреднение учитывает различия фильтрации CSS и Canvas; допустимая разница 5/255. До исправления режим baseline сохраняет сравнимые снимки без утверждения cover.
