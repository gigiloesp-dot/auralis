## Почему исправлены таймеры возрождения

Все 2415 текущих обычных spawn уже имели интервал 30 секунд и уникальные ID. Подтверждения дублирования ID при streaming не найдено. Новые тесты в изолированной копии исходной контрольной точки воспроизвели три дефекта:

1. Явный ordinary descriptor с 11000 ms принимался без нижней границы.
2. Legacy/no-content экземпляр восстанавливал оставшееся wall-время как абсолютное значение уже продвинутого игрового таймера, что могло немедленно завершить ожидание.
3. Истёкшая legacy смерть без killedAt могла создать видимый живой экземпляр до проверки свободной точки.

Теперь обычный интервал ограничен снизу 30000 ms при создании вида и смерти. Дедлайны respawnAt/deadUntil используют абсолютное Date.now во всех режимах. Сохранённые killedAt учитываются при миграции старого короткого дедлайна; восстановленный мёртвый экземпляр сначала проходит проверку свободного места. Подземельные minions текущего посещения и независимые boss cooldowns сохранены. Схема сохранений не заменена.

Это доказанные исправления. Точная причина конкретного наблюдения пользователя на физическом телефоне не установлена: реального устройства в среде нет.
