# AUR-203 — определения первых 20 новых видов

Подготовлены **рабочие чистые фабрики данных**, но подключение к игровому миру ещё выполняет основной агент. Импорт `js/monsters/aur203Species.js` сам по себе не добавляет лагеря, предметы, текстуры или обработчики AI. Текущие 257 лагерей и их сохранения этим модулем не изменены.

## Контракт интеграции

- `createAur203MonsterTypes(baseTypes)` возвращает только 20 новых записей. Старые объекты не изменяются и не замораживаются. Функция не импортирует `monsters.js`, поэтому основной агент может безопасно собрать `MONSTER_TYPES` из старого реестра и результата фабрики без циклического импорта. Повторное использование уже занятого type ID вызывает ошибку.
- `AUR203_SPECIES_ART` содержит 20 законченных descriptor. Основной агент добавляет их в общий живой resolver. Старый `uniqueSpeciesEntries()` относится к исходному Task10; одного расширения `INTEGRATED_SPECIES_ART` недостаточно, если `monsterArt` продолжает искать только в старом Task10-layout.
- `buildReadyAur203Camps(region,{registeredTypes,registeredArt,materials,materialByLoot,speciesIds?})` собирает только готовые выбранные виды. Функция требует настоящий реестр типов, точные descriptor и зарегистрированные предметы с правильными loot mapping. Неполные данные вызывают ошибку вместо подмены волком или неизвестным предметом.
- Необязательный `speciesIds` позволяет подключать регион частями. Известны только эти 20 готовых видов; попытка активировать оставшиеся 64 по одним координатам запрещена. Порядок заданных ID не переставляет авторские лагеря.
- Координаты, ID, уровни, биомы и 11 позиций каждого лагеря копируются из закреплённого `AUR203_PLACEMENTS`. Функция возвращает новые замороженные объекты; исходные 257 лагерей и snapshot всех 84 добавлений не меняются.

Пример сборки после регистрации типов, изображений и предметов:

```js
const addedTypes = createAur203MonsterTypes(baseTypes);
const registeredTypes = {...baseTypes, ...addedTypes};
const registeredArt = {...existingArt, ...AUR203_SPECIES_ART};
const camps = buildReadyAur203Camps('forest', {
  registeredTypes,
  registeredArt,
  materials: AUR203_MATERIALS,
  materialByLoot: AUR203_MATERIAL_BY_LOOT
});
```

Материалы определены отдельным агентом в `js/equipment/aur203Materials.js`; `kind.loot` равен новому type ID, а `AUR203_MATERIAL_BY_LOOT` связывает его с отдельным тематическим материалом. Ни старые предметы, ни каталоги экипировки, шансы редкости или правила золота фабрика не меняет.

## Начальный баланс и реальные возможности движка

Все относительные HP/attack/defense, скорости и настройки времён являются **техническим начальным предложением для новых противников**, а не согласованным владельцем итоговым балансом. Они явно перечислены в `relativeStats`, `speed`, `abilityConfig` и `behaviorConfig` каждой записи.

Фабрика сохраняет базовый уровень исходного архетипа и его XP/gold. Она округляет только базовые HP/attack/defense с указанными множителями; итоговое масштабирование к уровню спота использует прежнюю формулу `monsterKind`. Поле определения `nativeLevel` означает уровень зарезервированного спота из provenance, а не замену исходного уровня архетипа. Обязательное 30-секундное возрождение задаётся явно. Ни один вид не превращается в босса.

Здесь используются только существующие `cleave`, `roots`, `charge`, `haunt`, `pounce`, `venom`, `stomp`, `fan`, `dive`, `burrow`, `frost`, `blink`. Все 40 выпусков способностей проверены через настоящий `tickMonsterAbility`: есть предупреждение, до завершения windup урона нет, затем появляется движение, урон или снаряд.

Полёт назначен стрекозе, медузе, каракатице и скату. Они используют прежнюю полётную коллизию: низкие камни допускаются, стены и высокие препятствия сохраняются. Сухопутные существа не получают полёт только ради прохождения препятствий. Радиусы всех новых существ не превышают 24, как при проверке размещения.

`behaviorConfig.guard/retreat/pack` содержит настройки нового модуля `aur203Tactics.js`. **Сам этот файл не устанавливает соответствующие hooks.** Основной агент должен вызвать тактическое обновление при AI, корректировку входящего урона при настоящем ударе, pack alert только для ближайших живых союзников того же лагеря и отмену состояний при смерти/выгрузке/выходе. Без этих hooks нельзя объявлять новые пассивные механики работающими в игре.

## Локальная интеграция реестра типов

По отдельному разрешению основного агента внесено минимальное подключение в `js/monsters/monsters.js`: прежний литерал переименован в `BASE_MONSTER_TYPES`, а экспорт объединяет его с `createAur203MonsterTypes(BASE_MONSTER_TYPES)`. Все 24 прежние записи и тело `monsterKind` сохранены точно. `monsterArt.js` уже использовал `integratedSpeciesArt`, поэтому его байты не изменялись и циклический fallback через `speciesAssets` не добавлялся.

До изменения сохранён снимок `docs/qa/aur203/old24-monster-types-e80.json` из e80d0efc6f12577d31364abfc8448d905f299227. Его SHA256: `d9f9fe7da847fab873dbe2c43b083b99097e334905880b06edcc73a5a8389791`. Отдельный тест удаляет только две новые строки и возвращает одно прежнее имя объявления, после чего требует точный исходный hash всего файла; также проверяются 24 прежних объекта, неизменённое тело формулы и точные 257 прежних descriptor.

После подключения общего реестра основным агентом реально разрешаются все 20 новых descriptor; новые типы получают свои имена, добычу, способности и тактическую конфигурацию через настоящий `monsterKind`. После полной проверки type/art/material реестров builder ставит `temporaryBestiary:false`: эти модели не являются повторно использованными временными картинками. Этот флаг не подменяет приёмку боя, AI-hooks или браузерный тест.
