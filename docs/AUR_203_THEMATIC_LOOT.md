# AUR-203: тематические материалы обычных монстров

## Фактическое исходное состояние

До этого изменения `materials(hero,type,rng)` обрабатывал только `type==='wolf'`. Клыки волка имели базовый шанс17,5%, шкура10% (до задания№4 они были35% и20%). Для остальных16 действительных `kind.loot` шанс тематического материала был **0**: строки `boar`, `bear`, `spider` и другие сами по себе не создавали предметы. Золото и экипировка выпадали отдельно.

## Изменение

Добавлены16 самостоятельных **материалов**, без слота экипировки, атакующих/защитных характеристик, торговли новым оружием или изменения старого каталога. Все названия имеют RU/EN/ES. Реальные обычные виды соответствующих семейств теперь используют эти предметы через существующие `rollMonsterLoot`, наземную добычу, окно подбора, стеки, инвентарь и сохранения. Предметы не добавляются в обычные сохранения автоматически.

Техническая настройка нового материала — один независимый шанс17,5% с существующим множителем удачи и прежним распределением редкости материалов. Это **новое предложенное значение**, повторно использующее имеющуюся базу клыка; оно не выдаётся за прежний шанс этих семейств или отдельно утверждённый баланс. Сначала выполняется прежний бросок экипировки и выбор предмета, затем дополнительный бросок материала: прежние результаты экипировки для одинакового RNG сохраняются. Волчий путь полностью прежний; **все пути боссов сохраняют прежние результаты и число обращений к RNG**, без новых материалов. Легендарные предметы и независимые группы боссов не изменены.

` saleValue:0 ` явно поддерживается действующей торговлей: новые материалы не продаются и не увеличивают приток золота. Будущие рецепты/цены/квесты для них здесь не выдуманы. Это ограничение нужно пересмотреть в отдельной экономической задаче.
