Не менять save keys v1/v2, не очищать localStorage, сохранять before-import backup и pending journal shared storage. Контролировать cooldown после паузы/reload и импорт без завершающего save старого героя. Все тесты с координатами/уровнями/летальными hit-вызовами называть fixtures; no-fixture journey отличается чтением сцены без изменений состояния.
