# Главное меню и средневековая тема

Контрольная точка до изменений: `756ed8ffaa7974d6ce5efd9cd94f90e642cd0049`.
Рабочая ветка: `codex/auralis-master-development`, PR #2. Main и stable-alpha не меняются.

## Реализовано

- Фон по приложенному эталону: арка, фонарь, потрёпанный грузинский флаг, замок, закат, деревня, река и мост. Отдельный прозрачный логотип AURALIS с мечом. Иллюстрации созданы генеративным инструментом по эталону, это близкое воспроизведение, а не исходный файл пользователя.
- Пять настоящих HTML-кнопок с SVG-иконками, фокусом, наведением и нажатием. Новая игра выбирает свободный слот; при заполнении всех слотов открывает выбор, ничего не перезаписывая. Перед записью занятость проверяется повторно.
- Продолжить открывает три существующих слота. Настройки используют действующий выбор языка. Авторы — отдельное локализованное окно. Выход завершает пребывание в главном меню экраном с объяснением закрытия вкладки: браузер не разрешает произвольно закрывать обычную вкладку. Удаления сохранений нет.
- Централизованный `css/medieval-theme.css`: токены палитры, поверхности, рамки, кнопки и карточки; компоненты `.auralis-panel`, `.auralis-button`, `.auralis-card` для будущих окон. Существующие выбор/создание, пауза, навыки, характеристики, инвентарь/сравнение, задания, NPC/торговля, хранилище, резервные копии и подтверждения используют эту же тему. Семантические цвета редкости, HP/MP и предупреждений сохранены.
- Графика меню — два WebP, суммарно 687540 байт; исходные генерации сохранены в рабочем каталоге. Нет новых игровых текстур Phaser или изменений потоковой загрузки.
- Новая браузерная проверка RU/EN/ES: пять кнопок, пять размеров от 740×320 до 1280×721, создание, настройки, авторы, выход, перезагрузка, пауза/инвентарь, защита трёх занятых слотов. Старые браузерные проверки сохранены; изменено только название входной кнопки с «Играть» на «Продолжить», путь через слоты тот же.

## Проверки и доставка

До финальной доставки проверять текущие журналы и CI. Не считать этот файл подтверждением публикации. Физическое Android-устройство недоступно; браузерная эмуляция не является приёмкой на телефоне.
