# Auralis — мобильная Action RPG

Играбельный лесной прототип на Phaser 3.90 / ES modules. Это ограниченная альфа-зона 2400×2400, а не весь мир из технического задания.

## Запуск

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте `http://localhost:8000`. На телефоне в той же Wi-Fi сети — `http://<LAN-IP-компьютера>:8000`, поверните экран горизонтально. Сервер не содержит авторизации: используйте доверенную сеть. Phaser загружается с jsDelivr, поэтому первый запуск требует интернета. Сборка не нужна.

## Что работает

- Три независимых персонажа, шесть классов, локальные сохранения и резервный исходный JSON.
- Сенсорный джойстик и удержание атаки одновременно; разные дальности, снаряды, критические/двойные удары, XP, уровень до42, пять характеристик.
- По пять навыков класса: изучение, ранги, четыре боевых слота, расход MP, перезарядки, лечение, защита и статусы.
- Девять слотов экипировки, инвентарь60, стаки100, сравнение вещей и визуальные элементы экипировки.
- HP/MP-зелья, регенерация вне боя, безопасная деревня, смерть и возрождение.
- 8 волков, 4 кабана, 4 разбойника, мини-босс Страж чащи с предупреждаемым ударом и редкой наградой. Дальние враги отключаются.
- Мира: задание на5 волков, награда, покупка зелий и продажа материалов. Борин: общее хранилище100 ячеек с восстановлением прерванного переноса.
- Мини-карта, пауза, окна и автосохранение каждые5 секунд, включая открытые игровые панели.

После создания героя поговорите с Мирой у перекрёстка. Волки — восточнее деревни; кабаны — на северо-востоке, разбойники — на юго-западе, Страж — на юго-востоке. Очки навыков и характеристик выдаются при повышении уровня.

## Проверки

```sh
npm ci
npm run check
npm test
npx playwright install chromium
npm run test:browser
```

Для системного Chromium: `CHROMIUM_PATH=/usr/bin/chromium npm run test:browser`. Сценарий сам запускает локальный HTTP-сервер; снимок сохраняется в `work/browser/smoke-final.png`. Браузерный тест использует обычные UI-действия и подготовку состояния для уровней/боевых ситуаций, чтобы не требовать длительного прохождения.

Подробности: [архитектура](docs/ARCHITECTURE.md), [проверки и ограничения](docs/PLAYTEST.md), [оставшиеся этапы](docs/ROADMAP.md).

RU — основной язык. Меню и новые NPC/торговля/хранилище поддерживают RU/EN/ES; старые игровые панели ещё требуют полной локализации. Производительность60FPS на физическом Android пока не подтверждена.
