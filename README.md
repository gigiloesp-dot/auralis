# Auralis — мобильная Action RPG

Одиночная браузерная изометрическая RPG на Phaser 3.90 / ES modules. Рабочая master-интеграция содержит три больших региона, потоковую загрузку, бой, NPC, задания и подземелья. Окончательный арт и проверка на физическом Android ещё не завершены; это не заявление о полном выполнении ТЗ.

## Запуск

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте `http://localhost:8000`. На телефоне в той же Wi-Fi сети — `http://<LAN-IP-компьютера>:8000`; поверните экран горизонтально. Используйте доверенную сеть: этот простой сервер не содержит авторизации. Сборка не нужна. Phaser включён в `assets/vendor/` с MIT-лицензией, внешняя CDN для запуска не требуется. Это не означает наличие service worker или offline-кэша сайта.

## Доступно в игре

- Три региона: лес12000×12000, север14000×14000, древние земли15000×15000; дороги/реки/мосты, переходы, карта и мини-карта. Чанки512 и отдельный stream врагов загружают только ближайшее окружение.
- 254 лагеря / 2415 обычных монстров, 12 мини-боссов / 6 мировых боссов, отдельная арена. Урон активирует ограниченное преследование; вне боя работают патрули и паузы. Внешнее обычное возрождение — 30 секунд; сохраняются здоровье, агрессия и таймеры смерти.
- 7 поселений /21 NPC: задания, обычные и особые магазины, сведения, общее хранилище.104 задания связаны с событиями мира и сохраняют прогресс.
- 12 подземелий с уровневым допуском и тремя сложностями, комнатами и 1–3 боссами. Обычные враги остаются мёртвыми до нового посещения, включая reload; боссы имеют независимые часовые таймеры по сложности. После завершения доступен добровольный портал к тому же входу; обычный выход сохранён.
- Шесть классов,30 действующих навыков, ранги и4 боевых слота; настоящие снаряды, LOS, крит/двойной удар, статусы, лечение/защита и классовые механики.
- Три независимых героя, уровни1–42, пять характеристик,9 слотов экипировки, сумка60, стаки100, shared storage100, торговля и зелья. Предметы выпадают на землю анонимными мечами, доспехами или деревянными сундуками; подбираются касанием вблизи. Полный инвентарь оставляет предмет на месте; streaming/reload не теряют и не дублируют добычу.
- Сенсорное управление несколькими пальцами, пауза, адаптивные панели, RU/EN/ES, автосохранение5с и пользовательский экспорт/импорт JSON с резервами.
- Изометрическая проекция и подключённые рисованные атласы: шесть нейтральных баз героев без встроенной экипировки, 23 вида монстров, 21 NPC и 44 босса. Девять слоёв экипировки рисуются отдельно; прежние спрайты сохранены. NPC ещё цельные одетые образы, отдельные клипы и предметные PNG требуют доводки. Деревья, дома и портреты сохранены.

После создания героя поговорите с Мирой в стартовой деревне и выберите первое поручение. Волки находятся восточнее; пользуйтесь картой и координатами цели в диалоге. Подземелье№1 доступно с5уровня у координат1820,1780. Переход открывает кнопку при приближении к указанному на карте порталу.

## Проверки

```sh
npm ci
npm run check
npm test
npm run test:browser
```

Для системного Chrome/Chromium задайте `CHROMIUM_PATH=/usr/bin/chromium`. Если браузер отсутствует, установите совместимый Chrome или `npx playwright install chromium` и необходимые для своей ОС библиотеки. CI использует предустановленный Chrome GitHub runner и не запускает APT-установку Playwright.

Браузерные сценарии самостоятельно поднимают HTTP-сервер и закрывают его после проверки. Они нажимают реальные UI-кнопки и используют явно обозначенные fixtures для уровней, ресурсов, координат и некоторых попаданий. Это воспроизводимые integration tests, не полное ручное прохождение1–42. Снимки записываются в `work/browser/`.
