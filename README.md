# Auralis — Action RPG

Новая мобильная RPG (альфа). Проект LAST 60 полностью заменён.

## Запуск

Открыть index.html через статический HTTP-хостинг. GitHub + Cloudflare Workers автоматически публикуют файлы после успешного деплоя. Движок Phaser 3 загружается через CDN.

## Архитектура

- index.html — оболочка
- css/game.css — сенсорный HUD
- js/main.js — загрузка Phaser
- js/world/WorldScene.js — первая лесная сцена, камера, NPC, управление
- js/systems/save.js — версионированное автосохранение

## Текущий этап

Прототип перемещения: горизонтальный экран, 8 направлений, базовая анимация частей тела, деревья, дома, NPC, столкновения и автосохранение координат. Атака пока только визуальная. Классы, бои, предметы, квесты и настоящий арт будут реализованы далее. Не считать эту версию завершённой RPG.
