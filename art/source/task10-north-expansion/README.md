`manifest.json` preserves stable IDs, proposed names in RU/EN/ES, actual baseType, actual biome and locomotion, and two proposed existing ability IDs. These patterns are proposals for parent integration; no current statistics or abilities were changed.

Every runtime PNG is 1024×1152 transparent RGBA, eight columns (n/ne/e/se/s/sw/w/nw) by six rows (idle/run-a/run-b/attack/hurt/death), 128×192 cells. These are 48 separate drawn poses, including two movement phases and separate hurt/death drawings. They are not six full multi-frame animation clips. Per-pose measured footlines, scale and annotation height are in `js/assets/northExpansionArt.js`, exporting `NORTH_EXPANSION_ART`.

All original generated sheets are preserved as `*-original.png`, first imagegen spacing/background repairs as `*-reflow.png`, second imagegen spacing repairs as `*-reflow2.png` where needed, and final bear registration repair as `*-reflow3.png`. None were deleted or overwritten. Original generation outputs also remain in `/workspace/generated_images`. These models are original drawings with independently different silhouettes, not recolors of existing creature images.

Mechanical Canvas packing only scales whole equal source cells into a 96px area within required gutters. No programmatic recoloring, anatomy invention, background segmentation or semantic image cleanup is used. Earlier reflows of jackal/golem/bear/spindle/bell still had neighboring fragments; these were repaired with imagegen. Final beige composites for all eight models and all 384 poses were visually inspected: no neighboring severed fragments, body clipping or lost extremities visible. Directions and action states remain recognizably different. Generated directional proportions and some fine material details naturally vary. Some source sheets retain low-alpha background traces from generation; the composited packed poses are the visual acceptance evidence.

Rebuild from repository root: `node scripts/pack-north-expansion.cjs`.
Validate: `node scripts/validate-north-expansion.mjs`.

`validation.json` records eight models, 384 nonempty poses, PNG SHA256s, dimensions and minimum body pixels. Validation checks all eight directions and six distinct alpha silhouettes in each direction, exact footlines, more than 60% fully transparent atlas texels, and ZERO alpha in every cell's x<12 / x>=116 / y<70 / y>=174 gutters.

Each decoded runtime atlas is 4,718,592 bytes. Register lazily through the existing texture cache and preserve lease cleanup; avoid globally preloading eight new sheets. Parent still must integrate the stable IDs, names, real ability callbacks, preserve current stats/drops, check camps and 30-second respawn/save-reload, browser and physical Android acceptance before counting these as live species. No shared registry, runtime, species catalog, ledger, tests, package scripts, Git refs or hosting were edited by this subtask.
